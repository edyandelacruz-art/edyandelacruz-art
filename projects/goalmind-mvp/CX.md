# GoalMind — CX / Journey

## Happy path
1. Student opens app: no login wall.
2. Taps Jugar.
3. Picks subject, difficulty and timer.
4. Starts within three decisions.
5. Answers through goal zones.
6. Receives goal/save + one-sentence explanation.
7. Finishes five-question match and sees precision, points and next target.

## Friction controls
- No account required in demo/training.
- Teacher flow exposes a single join code.
- Keyboard A–D works for desktop demos.
- Timeout is treated as a learning event, not a dead screen.
- Progress metrics describe learning, not only points.
