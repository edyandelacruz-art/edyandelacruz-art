# Design skill stack

Curated sources already reviewed in Edyan's GitHub ecosystem:
- `edyandelacruz-art/ui-ux-pro-max-skill` — design intelligence, patterns, accessibility and token architecture.
- `edyandelacruz-art/impeccable` — critique/audit/polish workflow and anti-generic-design rules.
- `edyandelacruz-art/npxskillui` — reverse-engineer design systems from URL/repo/code.
- `JacobLinCool/ux-discovery-interviewer-skill` — structured discovery, journeys, pain points and opportunities (MIT).
- `edyandelacruz-art/playwright-cli` — browser testing/visual QA support.

For this MVP these are activated through `.agents/skills/goal-game-product-design/SKILL.md`, with project context in `PRODUCT.md`, `DESIGN.md` and `CX.md`. This keeps the project portable across coding-agent harnesses instead of coupling the UI to one vendor.
