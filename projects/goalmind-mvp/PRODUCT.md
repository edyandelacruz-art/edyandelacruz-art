# GoalMind — Product Context

## Product lane
Mobile-first educational game for grades roughly 6–11. The primary interaction is a football penalty: academic answer options map to physical zones of the goal. The student should feel that they are playing first and answering a quiz second.

## Primary users
- Student: wants a fast, low-friction competitive activity with immediate feedback.
- Teacher: wants to launch a short class session and see performance by student/question.

## Core loop
Choose subject → read question → shoot at answer zone → goal/save feedback → micro-explanation → next question → match summary.

## Non-goals for MVP
No account system, no realtime multiplayer backend, no content authoring CMS, no payments.
