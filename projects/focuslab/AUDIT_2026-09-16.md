## What is actually implemented

### Product and UX
- Product thesis and experimental framing defined.
- Six-game MVP scope defined.
- Eight cognitive skills defined.
- Seven desktop screens designed in Figma.
- Current local UI simplified and modernized after usability review.
- Empty states now replace fabricated dashboard values.

### Frontend runtime
- Next.js / React application shell.
- Home, Session Setup, Training Arena, Results, Progress, Explore and Profile.
- Shared game host.
- Runner, Tetris, Road Dodge, Pong, Snake and Memory Grid implemented.
- Timed question overlays.
- Adaptive pause policy: `pause_all`, `pause_content`, `continue_all`.
- Adaptive game speed and answer-time logic.
- Browser narration through Web Speech API.
- Local session persistence.
- Baseline session condition without secondary game task.
- Matched baseline-vs-dual-task comparison using content fingerprint + cognitive skill.

### Content path
- Real editable academic text input.
- Text normalization and segmentation.
- Traceable local cloze-question generation from source sentences.
- Content fingerprinting for matched comparisons.
- Optional YouTube/source URL stored as reference metadata.

Important distinction: a YouTube URL is currently classified as `youtube_reference`, not `youtube_transcript`, because transcript retrieval is not connected yet.

### Real metrics currently captured
- Learning accuracy.
- Average response latency.
- Game score.
- Collisions / task errors.
- Final adaptive level.
- Pause policy.
- Session condition.
- Content identity and fingerprint.
- Per-skill observed accuracy from stored sessions.
- Per-final-level observed accuracy from stored sessions.
- Matched baseline dual-task accuracy cost and latency cost when a valid baseline exists.

## Audit corrections made in v0.6

The following were identified as misleading or insufficiently connected and were removed or corrected:

1. Removed arbitrary `Focus Index` presentation.
2. Removed arbitrary composite `Cognitive score` presentation.
3. Removed the starting-load slider because it was not wired to the training engine.
4. Removed the fixed `12 min` session label because session duration was not enforced by the runtime.
5. Corrected YouTube source typing so a URL is not presented as a retrieved transcript.
6. Replaced illustrative progress values with empty states or session-derived values.
7. Baseline comparison now reports `not available` when no matched baseline exists rather than estimating interference from unrelated variables.

## Important remaining technical gaps

### Backend / identity
- No Supabase project dedicated to FocusLab yet.
- No authentication.
- No multi-user persistence.
- No student/teacher/admin roles.
- No cloud longitudinal learner profile.

### Content intelligence
- No direct YouTube transcript retrieval.
- No semantic AI concept extraction.
- No semantic question generation/validation.
- No difficulty calibration based on item complexity.

### Analytics / research validity
- Switching-cost protocol not implemented.
- Delayed recall protocol not implemented.
- Transfer-test protocol not implemented.
- Baseline/dual comparisons are implemented but still require empirical validation and sufficient repeated observations.
- Current per-level curve uses session final level, not full within-session exposure history.
- Teacher/class analytics are not implemented.

### Infrastructure
- Public alpha exists on AppDeploy and currently reports clean frontend/backend/network QA.
- Dedicated FocusLab GitHub repository does not yet exist; project records are currently stored under `edyandelacruz-art/edyandelacruz-art/projects/focuslab`.
- Vercel production project is not connected in the current workspace.
- Supabase free project capacity is currently occupied.
- Production monitoring/error tracking is not yet configured.
